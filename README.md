# رفيق المشرف الذكي (Rafiq Al-Mushrif)

**تطبيق المشرفين التربويين لأتمتة تقارير الزيارات الصفية** — يحوّل سرد المشرف لمجريات الحصة (كتابةً أو صوتيًا) إلى تحليل وصفي احترافي وتوزيع علامات على مؤشرات الأداء الرسمية، مع تصدير التقريرين (الوصفي وعلامات الأداء) بصيغتَي PDF و Excel.

**روابط رسمية:**

- **نسخة الويب (تعمل الآن):** https://eshrafyatta2015-creator.github.io/rafiq-almushrif/
- **الإصدارات وملفات APK:** https://github.com/eshrafyatta2015-creator/rafiq-almushrif/releases
- **المستودع:** https://github.com/eshrafyatta2015-creator/rafiq-almushrif

> لتفعيل الميزات الذكية (تحليل Gemini) في نسخة الويب أو APK: انشر خادم `server.ts` مع `GEMINI_API_KEY` ثم أدخل رابطه في **الإعدادات ← رابط الخادم الذكي**. باقي المزايا تعمل دون إنترنت.

## أبرز المميزات

- **واجهة عربية كاملة RTL** مع خطوط عربية مضمّنة داخل التطبيق (تعمل دون إنترنت).
- **شاشة افتتاحية أنيقة** + **شاشة رئيسية** منظمة بالوظائف الأساسية.
- **مساعد ذكي (Gemini API)**:
  - تحليل مجريات الحصة إلى: نقاط القوة، جوانب التطوير، تحصيل الطلبة، ملحوظات، توصيات للمعلم والمدير.
  - تقدير ذكي لعلامات مؤشرات الأداء (100 درجة) بناءً على التحليل الوصفي.
- **إملاء صوتي عربي** في كل الحقول (على المتصفحات الداعمة).
- **قوالب تقارير رسمية** مطابقة لنماذج الإشراف التربوي في فلسطين (ترويسة الوزارة + شعار فلسطين).
- **تصدير PDF و Excel** للتقرير الوصفي وتقرير العلامات.
- **مشاركة التقرير** عبر رابط مُشفّر (نسخة الويب).
- **أرشيف محلي على الجهاز** للحفظ والاسترجاع حسب رقم هوية المعلم + أرشيف سحابي اختياري.
- **حفظ تلقائي للمسودة** — أغلق التطبيق وعد لتكمل من حيث توقفت + مؤشر «حفظ تلقائي» في الترويسة.
- **نسخ احتياطي واستعادة** — تصدير كل السجلات والمسودة والإعدادات كملف JSON واستعادتها على أي جهاز.
- **دليل استخدام سريع** داخل التطبيق (خمس خطوات + نصائح).
- **تقدير عام بالحروف** (ممتاز/جيد جدًا/جيد/مقبول) يظهر في واجهة التقييم وتقرير العلامات وملخص المشاركة.
- **نسخ ملخص التقرير نصيًا** للمشاركة عبر واتساب أو البريد بضغطة واحدة.
- **أدخل حقل التخصص ورقم الزيارة** وتطبيع الأرقام العربية تلقائيًا في حقول الهوية.
- **حد ذكي للعلامات** — يمنع تجاوز القيمة القصوى لكل مؤشر يدويًا أو عبر التقدير الذكي.
- **أسلوب تحليل قابل للتبديل** (مختصر/متوازن/مفصّل) من الإعدادات.
- **PWA**: واجهة قابلة للتثبيت على سطح المكتب والهاتف + تخزين مؤقت للعمل دون إنترنت (نسخة الويب).
- **تحقق من المدخلات** ورسائل خطأ عربية واضحة + تنبيهات Toast + حالات تحميل.
- **دعم الأجهزة اللوحية والهواتف** بجميع الأحجام.

| الطبقة | التقنية |

## التشغيل المحلي

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) ضبط مفتاح الذكاء الاصطناعي (يُستخدم في الخادم فقط، ولا يُرفع إلى Git)
```

## الميزات الذكية (Backend)

تحليل المجريات وتقدير العلامات يتمان عبر خادم **server.ts** معًا مع مفتاح Gemini API — **لا يُوضع المفتاح أبدًا داخل تطبيق الهاتف**.

| المسار | الوظيفة |
| --- | --- |
| `GET /api/health` | فحص صحة الخادم |
| `POST /api/analyze-proceedings` | تحليل نص مجريات الحصة |
| `POST /api/analyze-performance` | تقدير علامات مؤشرات الأداء |

### نشر الخادم (مطلوب لتفعيل الميزات الذكي)

انشر الخادم على أي استضافة تدعم Node.js (VPS، Railway، Render، Fly.io...) مع متغيّر البيئة `GEMINI_API_KEY`، ثم:

- **نسخة الويب:** اربط النطاق بالخادم — التطبيق سيعمل مباشرة (نفس الأصل).
- **نسخة APK:** افتح التطبيق ← **الإعدادات** ← أدخل **رابط الخادم الذكي** (مثال: `https://api.example.com`).

> بدون الخادم يعمل التطبيق بشكل كامل في جمع البيانات والتحرير والحفظ المحلي والتصدير PDF/Excel يدويًا؛ وتظهر رسالة عربية واضحة عند محاولة استخدام الميزة الذكية.

## بناء ملف APK

### الخيار الأول: تلقائيًا عبر GitHub Actions (موصى به)

عند الدفع إلى الفرع الرئيسي أو إنشاء وسم `v*`، يبني سير العمل `.github/workflows/android.yml` ملفات APK ويرفعها إلى:
- **Actions → Artifacts** (كل بناء)
- **GitHub Releases** (عند الوسوم)

### الخيار الثاني: محليًا على Windows

```powershell
# 1) تثبيت المتطلبات (مرة واحدة)
npm install
#    ثبّت JDK 17 و Android SDK (platform-34 + build-tools;34.0.0)
#    أو استخدم Android Studio لإدارة SDK

# 2) تجهيز وإنشاء APK
npm run android:sync
cd android
.\gradlew.bat assembleDebug assembleRelease

# 3) النتائج
# android\app\build\outputs\apk\debug\app-debug.apk   ← نسخة اختبار (موقّعة بتوقيع تجريبي)
# android\app\build\outputs\apk\release\app-release.apk ← نسخة توزيع (موقّعة إن وُجدت المفاتيح)
```

> على Linux/macOS استخدم `./gradlew` بدلاً من `gradlew.bat`.

### توقيع نسخة التوزيع (Release)

1. أنشئ مفتاح توقيع محليًا (لا يُرفع إلى المستودع):

```bash
keytool -genkeypair -v -keystore android/keystore/release.keystore \
  -alias rafiq -keyalg RSA -keysize 2048 -validity 10000
```

2. أنشئ ملف `android/keystore.properties` (مُستبعد من Git تلقائيًا):

```properties
RELEASE_KEYSTORE_FILE=../keystore/release.keystore
RELEASE_KEYSTORE_PASSWORD=your_password
RELEASE_KEY_ALIAS=rafiq
RELEASE_KEY_PASSWORD=your_password
```

3. أعد بناء `assembleRelease` — يخرج APK موقّعًا جاهزًا للتوزيع.

### إعداد التوقيع في GitHub Actions (اختياري)

لإنتاج نسخة Release موقّعة تلقائيًا، أضف أسرار المستودع:

| السر | القيمة |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | ملف `release.keystore` مُحوّل إلى Base64 (`base64 -w0 release.keystore`) |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة مرور الـ keystore |
| `ANDROID_KEY_ALIAS` | اسم المفتاح |
| `ANDROID_KEY_PASSWORD` | كلمة مرور المفتاح |

بدون هذه الأسرار ينتج سير العمل نسخة **Debug** موقّعة وقابلة للتثبيت دائمًا.

## تثبيت التطبيق على Android

1. انسخ `RafiqAlmushrif.apk` (أو `RafiqAlmushrif-debug.apk`) إلى الهاتف.
2. افتح الملف ← عند الطلب فعّل **«تثبيت التطبيقات من مصادر غير معروفة»** لمتصفح/تطبيق الملفات.
3. ثبّت التطبيق باسم **رفيق المشرف**.
4. لأول استخدام: افتح **الإعدادات** وأدخل رابط الخادم الذكي (إن أردت الميزات الذكية).

> الملفات المبنية محليًا توضع في مجلد `releases/`، وملفات APK مُستبعدة من Git (تُرفق في إصدارات GitHub بدلًا من ذلك).

## الأمان

- مفتاح Gemini API يبقى على الخادم فقط (`GEMINI_API_KEY`) — لا يُدمج في التطبيق ولا في المستودع.
- ملفات `.env*` و`*.keystore` و`keystore.properties` مُستبعدة من Git.
- التطبيق لا يطلب أي أذونات حساسة؛ إذن واحد فقط: `INTERNET`.
- الأرشيف السحابي اختياري تمامًا والتخزين الافتراضي محلي على الجهاز.

## استكشاف الأخطاء

| المشكلة | الحل |
| --- | --- |
| زر التحليل الذكي يفشل | تأكد من نشر الخادم وضبط رابطه في الإعدادات ومن وجود `GEMINI_API_KEY` |
| الإملاء الصوتي لا يعمل | غير مدعوم في WebView الخاص بـ Android — استخدم الكتابة اليدوية أو المتصفح |
| فشل بناء Gradle | تأكد أن `JAVA_HOME` يشير إلى JDK 17+ وأن `sdk.dir` صحيح في `local.properties` |
| خطوط عربية غير جيدة | الخطوط مضمّنة داخل التطبيق؛ أعد البناء بعد `npm run build` |
